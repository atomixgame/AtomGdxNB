# Milestone Plan: AtomGdx Studio v0.1.0

## 1. Executive Vision
**AtomGdx Studio v0.1.0** establishes a consolidated, next-generation Integrated Game Development Environment built upon the NetBeans Rich Client Platform (RCP) and Gradle build ecosystem, dedicated specifically to the LibGDX framework. 

Historically, LibGDX developers have relied on a disparate collection of standalone desktop utilities (Liftoff, Particle Editor, Skin Composer, Texture Packer, HyperLap2D, Hiero, Model Viewer). AtomGdx Studio bridges these silos into a seamless, high-performance IDE with modern polyglot language tooling, Android & Web deployment pipelines, and AI copilot & MCP integrations.

---

## 2. Core Milestone Deliverables

### Phase 1: Foundation & Sci-Fi Branding
- [x] Application branding assets: Splash screen banner, window icons (16px to 512px), title tokens, and sci-fi aesthetic theme.
- [x] i2c standard documentation layout (`docs/plan/`, `docs/todo/`, `docs/howto/`, `docs/design/`, `docs/progress/`, `docs/reports/`, `docs/tooling/`).
- [ ] NetBeans Platform suite skeleton and module structure configured with Gradle build.

### Phase 2: Project Management & Multi-Platform Engine
- [ ] **Liftoff Project Generator**: Embedded project creation wizard with customizable backend targets (Desktop LWJGL3, Android, TeaVM Web, RoboVM iOS) and libraries (Ashley, Box2D, FreeType, gdx-ai, gdx-gltf).
- [ ] **Gradle Build Engine**: Deep Gradle Tooling API integration for running, debugging, testing, and continuous asset packaging.
- [ ] **Android & Web Deployment**:
  - Android ADB device detector, AVD emulator launcher, one-click debug runner, and Logcat console.
  - TeaVM / GWT local web server with automatic browser opening and live reloading.

### Phase 3: Consolidated LibGDX Tool Suite
- [ ] **2D & 3D Particle Editors**: Interactive NetBeans TopComponents with real-time viewport, timeline graphs, emitter parameters, and preset loading.
- [ ] **Scene2D / VisUI Skin Composer**: Visual skin editor with live widget previews, color palette manager, font manager, and JSON/atlas exporter.
- [ ] **2D Scene & Level Designer (HyperLap2D paradigm)**: Layer hierarchy, composite items, Box2D physics polygon editor, Box2DLight placement, and camera framing.
- [ ] **Texture Packer & 9-Patch Studio**: Multi-atlas batch packer, whitespace trimming, padding controls, and interactive 9-patch slice editor.
- [ ] **Hiero & FreeType Font Generator**: SDF / MSDF distance-field generator, TTF/OTF character subset rasterizer, padding/shadow effects.
- [ ] **3D Model & GLSL Shader Viewer**: 3D viewport for `.g3db`, `.g3dj`, `.gltf`, `.glb` models, PBR material preview, animation player, and live GLSL shader editor.
- [ ] **Media Inspector**: Audio waveform visualizer (WAV, MP3, OGG) with pitch/pan playback tests, and high-res sprite inspector.

### Phase 4: Polyglot Language Intelligence
- [ ] Code syntax highlighting, indentation, error annotations, and templates for:
  - Java, Kotlin, Groovy
  - JavaScript, HTML, CSS
  - JSON, YAML, XML
  - GLSL Vertex (`.vert`), Fragment (`.frag`), and General Shaders (`.glsl`).

### Phase 5: AI Assistant & Model Context Protocol (MCP)
- [ ] Dockable AI Assistant panel supporting multiple providers (Gemini, Claude, OpenAI, Ollama local models).
- [ ] In-context code generation, GLSL shader explanation, and math/physics helper.
- [ ] **MCP Server**: Exposing active LibGDX project structure, scene hierarchy, texture atlas metadata, and shader source code to AI agents.
- [ ] **Generative Art Tools**: In-IDE prompt-to-texture generation and automatic atlas integration.

## 3. Release Criteria & Quality Gates
1. Clean Gradle build across all modules with Java 21 LTS.
2. Verified launch of the NetBeans Platform application suite with branded sci-fi UI and splash screen.
3. Functional project generation and build execution for Desktop, Android, and Web backends.
4. Comprehensive verification reports documented in `docs/reports/`.
