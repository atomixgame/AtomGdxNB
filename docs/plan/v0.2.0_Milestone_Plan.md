# Milestone Plan: AtomGdx Studio v0.2.0

## 1. Executive Vision
**AtomGdx Studio v0.2.0** elevates the IDE into a complete visual game creation suite by introducing device resolution simulations, multi-target build profiles, comprehensive keyframe animation timelines, advanced PBR material and lighting studios, and Ashley Entity Component System (ECS) inspection.

---

## 2. Core v0.2.0 Work Packages

### Track 1: Multi-Device Resolution Preview & Build Profiles
- **Unity-Style Game View / Resolution Switcher**:
  - Embedded in 2D (`Scene2DTopComponent`) and 3D (`Scene3DEditorTopComponent`) viewports.
  - Device presets:
    - *Phones*: iPhone 15 (1179x2556), iPhone SE (750x1334), Google Pixel 8 (1080x2400), Samsung Galaxy S24 (1080x2340).
    - *Tablets*: iPad Pro 12.9" (2048x2732), iPad Air (1640x2360), Galaxy Tab S9 (1600x2560).
    - *Desktop / Handheld*: 1080p FHD (1920x1080), 1440p QHD (2560x1440), 4K UHD (3840x2160), Steam Deck (1280x800), Nintendo Switch (1280x720).
    - *Aspect Ratios*: 16:9, 16:10, 21:9, 4:3, 19.5:9, Free Aspect.
  - Orientation toggle (Landscape / Portrait).
  - Safe-Area notch and home bar visualization overlays.
- **Gradle Build Configuration Matrix**:
  - Dedicated BuildConfig panel supporting target platform selection (`desktop`, `android`, `html`, `ios`), build types (`debug`, `release`), and custom Gradle task arguments.

### Track 2: Keyframe Timeline & Animation Player Studio
- **`TimelineTopComponent`**:
  - Multi-track dope-sheet editor for 2D spritesheet sequences, entity transform keyframes, and 3D glTF skeletal animations.
  - Transport controls: Play, Pause, Stop, Step Forward, Step Backward, Loop, and Time Scrubber.
  - Dynamic binding to selected scene item or 3D model node.

### Track 3: PBR Material & Environment Lighting Studio
- **`MaterialEditorTopComponent`**:
  - Real-time PBR material property inspector: Albedo color/texture, Metallic, Roughness, Normal map, Ambient Occlusion, Emission, Transmission, and Clearcoat.
  - Direct live linkage to active GLSL shaders and glTF materials.
- **`LightingEnvironmentTopComponent`**:
  - HDRI Skybox loader with IBL irradiance calculations.
  - Sun directional lighting with pitch/yaw sliders, color temperature, and shadow bias.

### Track 4: Ashley ECS Component Registry & Prefabs
- **`ComponentRegistryTopComponent`**:
  - Static and runtime reflection scanner detecting `@GdxComponent` and `@GdxSystem` implementations in the user project.
  - Visual "+ Add Component" palette integrated into the 2D & 3D inspectors.
- **Prefab System**:
  - Serializing entity templates to `.prefab` descriptors and managing live scene instance links.

### Track 5: Viewport Interactive 3D Transform Gizmos
- **Direct Canvas 3D Gizmos**:
  - Translation: RGB orthogonal arrow handles.
  - Rotation: Euler gimbal rings.
  - Scale: Boxed axes handles.
  - Coordinate space toggle (World vs Local).
