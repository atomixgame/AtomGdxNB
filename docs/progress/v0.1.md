# Development Progress: AtomGdx Studio v0.1.80

## Implementation Timeline & Changelog

### Version v0.1.80 (Latest)
- **Native Binary glTF (.GLB) & JSON glTF (.GLTF) Model Loader (`GlbModelLoader`)**:
  - Implemented high-performance binary GLB parser (`GlbModelLoader.java`) decoding binary header chunks (Magic `0x46546C67`), JSON chunks, and binary buffer views directly.
  - Parses real vertex accessors (`POSITION`, `NORMAL`, `TEXCOORD_0`), triangle indices (supporting `UNSIGNED_SHORT`, `UNSIGNED_BYTE`, `UNSIGNED_INT`), PBR metallic roughness materials, and node hierarchy.
  - Automatically calculates real bounding box, normalizes scale, and centers real 3D geometry in the LibGDX OpenGL viewport.
  - Verified loading official Khronos `DamagedHelmet.glb` (14,556 vertices, 46,356 indices, 3.77 MB) directly onto hardware OpenGL GPU backbuffer without procedural fallbacks.

### Version v0.1.79
- Resolved NetBeans Ant platform properties & `cluster.path` / `netbeans.dest.dir` configuration.
