# Development Progress: AtomGdx Studio v0.1.83

## Implementation Timeline & Changelog

### Version v0.1.83 (Latest)
- **Thread-Safe GLB Model Reloading & Switching**:
  - Resolved `RuntimeException: No OpenGL context found in the current thread` when changing models via UI controls (`JComboBox` on Swing EDT) in [`Model3DViewportListener.java`](file:///g:/GameDev/LibGDX/AtomGdx/AtomGdxNB/AtomGdxNB/modules/atomgdx-viewer-3d/src/main/java/com/atomgdx/viewer3d/ui/Model3DViewportListener.java).
  - Used `AtomicReference<File>` and `Gdx.app.postRunnable(...)` to ensure all native OpenGL buffers and textures (`new Mesh`, `new Texture`, `glGenBuffers`) are allocated strictly on the active OpenGL render thread.
  - Verified with automated test `DynamicGlbSwitchTest.java` seamlessly switching between `DamagedHelmet.glb`, `ToyCar.glb`, and `CesiumMilkTruck.glb`.
