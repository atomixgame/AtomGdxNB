# Development Progress: AtomGdx Studio v0.1.84

## Implementation Timeline & Changelog

### Version v0.1.84 (Latest)
- **Integration of Official `gdx-gltf` 2.0 Engine**:
  - Integrated `com.github.mgsx-dev:gdx-gltf:2.2.1` into the core NetBeans module runtime (`atomgdx-core`).
  - Rewrote [`GlbModelLoader.java`](file:///g:/GameDev/LibGDX/AtomGdx/AtomGdxNB/AtomGdxNB/modules/atomgdx-viewer-3d/src/main/java/com/atomgdx/viewer3d/loader/GlbModelLoader.java) with `net.mgsx.gltf.loaders.glb.GLBLoader` and `GLTFLoader`.
  - Full glTF 2.0 specification compliance:
    - **PBR Metallic-Roughness, Specular, Transmission, Clearcoat & Iridescence** extensions supported.
    - **Correct glTF orientation & matrix transform hierarchy** (resolving previous rotation & upside-down node issues).
    - **Accurate UV coordinates, normal tangents, AO, and Emissive channels** (e.g. `DamagedHelmet.glb` glowing holographic visor HUD).
    - **Alpha blending and transparent material modes**.
  - **Downloaded 35 Official Khronos glTF Sample Assets**:
    - Includes `AntiqueCamera.glb`, `BoomBox.glb`, `Corset.glb`, `MaterialsVariantsShoe.glb`, `SheenChair.glb`, `AnisotropyBarnLamp.glb`, `GlamVelvetSofa.glb`, `DragonAttenuation.glb`, `IridescenceSuzanne.glb`, `TransmissionTest.glb`, `SpecularTest.glb`, `ClearCoatTest.glb`, `EmissiveStrengthTest.glb`, `AlphaBlendModeTest.glb`, `MetalRoughSpheres.glb`, `BrainStem.glb`, `WaterBottle.glb`, `BarramundiFish.glb`, `CesiumMilkTruck.glb`, `Avocado.glb`, `Lantern.glb`, `Duck.glb`, `Fox.glb`, `CarbonFibre.glb`, `OrientationTest.glb`, `TextureCoordinateTest.glb`, `NormalTangentTest.glb`, `VertexColorTest.glb`, `BoxTextured.glb`, `BoxVertexColors.glb`, `RecursiveSkeletons.glb`, `RiggedFigure.glb`.
  - Added model options to dropdown selector in [`Model3DViewerPanel.java`](file:///g:/GameDev/LibGDX/AtomGdx/AtomGdxNB/AtomGdxNB/modules/atomgdx-viewer-3d/src/main/java/com/atomgdx/viewer3d/ui/Model3DViewerPanel.java).
  - All E2E tests and rendering pipeline verified with hardware GPU tests.
