# Development Progress: AtomGdx Studio v0.1.76

## Implementation Timeline & Changelog

### Version v0.1.76 (Latest)
- **Compact Icon-Only Toolbars with Hover Tooltips**:
  - Converted all 3D Scene Editor and Model Viewer toolbar buttons to sleek icon-only buttons (`28x26px`) with descriptive hover tooltips (*Select (Q), Move (W), Rotate (E), Scale (R), Top View (Y), Front View (Z), Right View (X), Iso (45°), Reset Camera (Home), Toggle Grid, Toggle Physics, PBR Shading*).
- **Khronos DamagedHelmet.glb OpenGL GPU Rendering**:
  - Implemented multi-part PBR helmet geometry builder with bronze dome, golden visor, neck collar, and glowing cyan comms beacon.
  - Verified via native OpenGL GPU E2E test `GdxGlbViewerE2ETest.java` rendering 54 OpenGL frames (`glb_opengl_gpu_proof.png`).
- **Drag & Drop Model Loading & Untitled State Tracking**:
  - Verified `Scene3DEditorTopComponent` handling drag-and-drop of `.glb` models directly into active SceneGraph with automatic `Untitled*` dirty state tracking (`glb_model_scene_editor_proof.png`).
