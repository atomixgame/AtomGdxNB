# Development Progress: AtomGdx Studio v0.1.75

## Implementation Timeline & Changelog

### Version v0.1.75 (Latest)
- **Comprehensive `.glb` Binary 3D Model Support**:
  - Full support across Project Structure Tree (`RealFileAssetNode`), File Actions, 3D Model Viewer (`Model3DViewerTopComponent`), and Inspector (`InspectorTopComponent`).
  - Verified inspection of real Khronos binary GLTF model `DamagedHelmet.glb` (3,685 KB) in E2E test `GlbAndSceneEditorE2ETest.java` (`glb_model_scene_editor_proof.png`).
- **Zero-Gap Fullscreen Canvas Architecture**:
  - Implemented `stretchCanvasToFit()` in `GdxAwtViewport.java` with dynamic boundary synchronization and zero margin borders, completely eliminating container gaps.
- **3D Scene Editor TopComponent in Editor Area**:
  - Registered `Scene3DEditorTopComponent` in NetBeans `editor` window mode with `"3D Scene Editor - Untitled*"` / `"Untitled Scene (Unsaved)"` status tracking.
  - Implemented full Drag & Drop support (`DropTarget`) enabling users to drop `.glb`, `.gltf`, `.obj`, and `.prefab.json` files directly onto the 3D viewport or SceneGraph to create nodes.

### Version v0.1.74
- Downloaded official Khronos sample models (`DamagedHelmet.glb`, `CesiumMilkTruck.glb`, `ToyCar.glb`, `Duck.glb`, `Fox.glb`, `BoomBox.glb`, `WaterBottle.glb`, `BarramundiFish.glb`, `BoxTextured.glb`).
- Added Fatcow icons to all toolbar buttons and SceneGraph tree nodes.
- Enhanced Asset Palette cards with color-coded thumbnail containers and full specifications.
