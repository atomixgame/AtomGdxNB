# Development Progress: AtomGdx Studio v0.1.72

## Implementation Timeline & Changelog

### Version v0.1.72 (Latest)
- **3D SceneGraph & Scene Structure**:
  - Upgraded `SceneStructureTopComponent` to dynamically switch between 2D Scene Hierarchy and 3D SceneGraph modes.
  - Implemented `SceneGraphTreePanel` with hierarchical node trees, `+ Create` dropdown menu (Mesh Primitives, Lights, Cameras, Prefabs), and node context menus.
- **3D GameObject & PBR Material Inspector**:
  - Implemented `Model3DInspectorPanel` with 3D Transform (X, Y, Z), Geometry stats (Vertices, Triangles), PBR Materials (Metallic, Roughness, Opacity), and Bullet Physics 3D.
  - Integrated into `InspectorTopComponent` with seamless NetBeans Lookup synchronization.
- **3D Asset Palette (`PaletteTopComponent`)**:
  - Implemented `Palette3DPanel` featuring Primitives (*Cube, Sphere, Cylinder, Cone, Plane, Capsule*), Prefabs (*Spacecraft Fighter, Asteroid Rock, SciFi Turret, Energy Shield*), and Materials (*Metallic Gold, Brushed Steel, Neon Cyan, Hull Paint, Glass*).
- **Test Lifecycle & JVM Module Opens Fix**:
  - Fixed test process termination by adding explicit `System.exit(0)` to all E2E visual test runners.
  - Configured JVM module opens (`--add-opens=java.base/java.net=ALL-UNNAMED` etc.) to eliminate Java 21+ reflection errors.
- **Visual Verification**:
  - E2E Test `SceneGraph3DPaletteE2ETest.java` captured visual verification proof `scenegraph_3d_palette_proof.png`.

### Version v0.1.71
- **Native LibGDX 3D OpenGL Viewport**:
  - Upgraded `Model3DViewerPanel` with `Model3DViewportListener` powered by LibGDX 3D pipeline (`PerspectiveCamera`, `ModelBatch`, `ModelInstance`, `Environment`, `DirectionalLight`).
  - Added interactive Orbit Camera controls (Left-drag orbit, Right-drag pan, Wheel zoom, Reset Camera).
  - Verified 3D rendering with `Gdx3DViewerE2ETest.java` capturing `model3d_opengl_gpu_proof.png`.
- **Audio & Media Studio**:
  - Implemented `MediaViewerPanel` with real-time waveform visualizer, playhead animation, volume/pan sliders, and looping controls.
  - Verified with `AudioMediaViewerE2ETest.java` capturing `media_viewer_proof.png`.
- **Fullscreen Canvas & Gap-Free Layouts**:
  - Removed fixed size constraints from `GdxAwtViewport.java` to stretch 100% edge-to-edge.
  - Enforced compact 20–22px row heights in `SceneItemInspectorPanel.java` to eliminate vertical height gaps.
- **DRY Utilities (`DarkThemeUtils`)**:
  - Centralized dark theme color tokens, compact input builders, and collapsible foldout sections in `atomgdx-core`.

### Version v0.1.70
- **Unity-Style 2D Inspector**:
  - Built collapsible foldouts for Transform, Box2D Rigidbody, Dynamic Light 2D, and `+ Add Component` popup menu.
- **SpriteSheet Editor & Image Viewer**:
  - Built sprite slicing tool with 1:1 Pixel Zoom and live animation player with FPS spinner and frame scrubber.
- **Real Gradle Execution**:
  - Hooked "Run Desktop (LWJGL3)" to execute `gradlew lwjgl3:run` with live output streaming.
- **NetBeans Suite XML Validation Fix**:
  - Fixed `nbproject/project.xml` compliance with `nb-module-suite-project/1` schema.
