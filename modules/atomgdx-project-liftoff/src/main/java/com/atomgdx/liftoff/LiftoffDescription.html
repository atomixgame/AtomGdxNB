LibGDX Project (Liftoff Generator)

Creates a new multiplatform LibGDX game project using the modern Gradle build pipeline.

Supported Platforms:

  • Core - Shared game logic
  • Desktop (LWJGL3) - Modern OpenGL desktop runtime
  • Android - Mobile runtime targeting latest Android SDKs
  • Web (HTML/TeaVM) - Browser runtime
  • iOS (RoboVM) - Native Apple mobile runtime

Supports official extensions (Box2D, Ashley, Controllers, Freetype, AI) and third-party libraries (VisUI, GDX-GLTF).
